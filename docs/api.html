API Reference

HeadlessUI.new()

Initializes a new UI session. Sets up CoreGui isolation, input management, and performance monitoring.

local UI = HeadlessUI.new()

UI:SetTheme(themeName)

Switch between built-in themes: "iOS Dark" or "Midnight".

UI.Renderer:SetTheme("Midnight")

UI:CreateWindow(config)

Creates a large, draggable window with advanced snapping.

local Window = UI:CreateWindow({Title = "HEADLESS v2"})

Tab:AddToggle(name, callback)

Adds a switch with smooth iOS-style animations.

Tab:AddToggle("God Mode", function(val) end)

Tab:AddSlider(name, min, max, default, callback)

Adds a precision slider with real-time value updates.

Tab:AddSlider("WalkSpeed", 16, 100, 16, function(v) end)

Tab:AddColorPicker(name, default, callback)

Adds a color selection component.

Tab:AddColorPicker("Accent Color", Color3.fromRGB(0, 255, 0), function(color) end)

UI:Notify(title, message, duration)

Triggers a responsive notification that scales to fit its content.

UI:Notify("Update", "System refined to 2,000+ lines of logic capacity.", 7)
