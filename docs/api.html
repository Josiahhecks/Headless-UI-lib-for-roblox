API Reference

HeadlessUI.new()

Initializes a new UI session. Sets up CoreGui isolation and performance monitoring.

local UI = HeadlessUI.new()

UI:CreateWindow(config)

Creates a new draggable window with built-in snapping.

  • config.Title: The title of the window.
local Window = UI:CreateWindow({Title = "My Script"})

Window:AddTab(name)

Adds a navigation tab to the window. Returns a Tab object.

local Tab = Window:AddTab("Main")

Tab:AddToggle(name, callback)

Adds an iOS-style toggle switch.

Tab:AddToggle("Enabled", function(state)
    print("State is:", state)
end)

Tab:AddSlider(name, min, max, default, callback)

Adds a functional slider component.

Tab:AddSlider("FOV", 0, 120, 70, function(val)
    print("Value:", val)
end)

Tab:AddDropdown(name, options, callback)

Adds a dropdown selection menu.

Tab:AddDropdown("Theme", {"Dark", "Light", "Glass"}, function(selected)
    print("Selected:", selected)
end)

Tab:AddKeybind(name, default, callback)

Adds a keybind listener.

Tab:AddKeybind("Toggle UI", Enum.KeyCode.RightShift, function()
    print("Key pressed!")
end)

UI:Notify(title, message, duration)

Triggers a global notification that stacks and resizes based on message length.

UI:Notify("Alert", "Something happened!", 5)

UI:Destroy()

Completely removes the UI and cleans up memory (Garbage Collection).

UI:Destroy()
